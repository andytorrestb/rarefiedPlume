# Documentation build dependencies -- pinned, tested together on 2026-10-28.

# Separate from the simulation package on purpose: pyproject.toml and Allsetup
# do not install any of this, and none of it is needed to run a case. Install
# into its own environment (Python >= 3.11, which Material 9.8, mkdocstrings 1.x
# and mkdocstrings-python 2.x require):
#
#     python3 -m venv .venv-docs
#     .venv-docs/bin/python -m pip install -r docs/requirements.txt
#     .venv-docs/bin/python -m mkdocs build --strict
#
# The site reads plumetools statically, so numpy, scipy, OpenFOAM and ParaView
# are NOT needed to build it. docs/_tools/run_examples.py is the exception: it
# executes examples and needs the package's own dependencies (pip install -e .).
#
# See docs/development/documentation.md, including the tooling status note
# (Material for MkDocs 9.8.0 announces an end of life on 2027-05-05; MkDocs 2.0
# is not compatible with it).
